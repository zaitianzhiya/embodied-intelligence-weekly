# 具身智能周报 — 反馈闭环规则

## 规则说明

每期周报末尾包含反馈入口，读者可以提交对事件分级、分类、权重的修正意见。
系统在下次运行时自动读取最近 4 周的反馈，注入 AI Prompt 以改进输出。

## 反馈文件格式

在 `feedback/YYYY-WNN.md` 中提交：

```markdown
- [x] 事件标题: 正确分类为 #vla-model（理由: 涉及 VLA 架构创新）
- [ ] 事件标题: 应该降权，只是营销发布没有实质性技术内容
- [x] 事件标题: 遗漏了关键数据——融资额实际为 5 亿美元而非 2 亿
```

## 标记含义

- `[x]` = 已确认的永久规则，每次都注入 Prompt
- `[ ]` = 待确认的建议，人工审核后再标记为 `[x]`

## 自动注入的 Prompt 内容

下次运行时，已确认的反馈会自动生成为 Prompt 节选：
```
## 反馈修正（来自上期读者）
- 上周"宇树 H1 量产"事件应归类为 #hardware + #industry，而非仅 #vla-model
- 目前关注优先级: 量产交付 > 论文发布 > 融资新闻
```
